# USR Advisory & Consultancy Services — Website

A multi-page, light-theme corporate website designed for GitHub Pages.

## Structure
- `index.html` — Home
- `about.html` — About USR
- `services.html` — Full service portfolio
- `research-intelligence.html` — Research & Intelligence
- `strategy-advisory.html` — Strategy & Advisory
- `financial-research.html` — Financial Research
- `financial-advisory.html` — Financial Advisory
- `ai-business-solutions.html` — AI Business Solutions
- `business-growth.html` — Business Growth Support
- `industries.html` — Industry coverage
- `approach.html` — Approach & engagement models
- `contact.html` — Contact
- `styles.css` — Shared visual system
- `script.js` — Mobile navigation and dynamic year
- `assets/` — Existing USR logo assets

## Publishing
Upload the contents of this ZIP to the GitHub repository root. Keep `index.html` at the root.

GitHub Pages should then publish the website from the repository's selected branch/root.
