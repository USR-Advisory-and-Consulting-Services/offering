# USR Advisory & Consultancy Services Website

A responsive static website ready for GitHub Pages.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your real company email.
2. Replace the temporary `assets/usr-brand.png` with your clean logo if you have the original logo file.
3. Add your real LinkedIn, phone and domain details if desired.
4. Review all financial/insurance wording and publish only services you are legally authorized to provide.

## Publish free with GitHub Pages
Create a public GitHub repository, upload the contents of this folder, then go to:
Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` → Folder: `/ (root)` → Save.

GitHub Pages hosts static HTML/CSS/JavaScript directly from a repository. A custom domain can be connected later.

## Contact form
The site intentionally uses a `mailto:` CTA rather than a paid backend. Replace the email address before publishing.
